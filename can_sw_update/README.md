# Software Update via the CAN Bus

## can-update
Protocol and state machines for transmitting and receiving devices. This library can be used in embedded, web, and desktop applications to implement the Larus Software Update Protocol.

## larus-fu (larus firmware upload)
Command-line tool for Linux to perform software downloads. The tool is currently under development and serves only as a demonstrator for data transmission via the CAN bus.

## stm32h7-test
Test program that runs on the Larus display.
